Galeries

Glisse des captures sur un projet : elles sont redimensionnées, rangées dans le bon dossier et affichées dans la card (collage puis diaporama). Rien ne part sur internet, tout reste sur ton disque.

Comment ça marche

  1. Ouvre le dossier Portfolio (celui qui contient index.html). Le navigateur demande l'autorisation de le modifier : accepte. Il s'en souviendra la prochaine fois.
  2. Choisis un projet à gauche, puis glisse tes images (ou colle une capture avec Ctrl+V). Range-les avec les flèches : les 3 premières forment le collage de la cover.
  3. Ajoute une légende si tu veux, floute les zones sensibles, puis clique Enregistrer. Les images vont dans assets/img/projects/<projet>/ et assets/data/galleries.js est mis à jour. Il ne reste qu'à commit et push.

Ce navigateur ne peut pas écrire dans un dossier. Ouvre cette page dans Chrome ou Edge.
